# Jumping Jax AI Phone and Birthday Marketing Goal

Build and productionize a Jumping Jax AI phone receptionist that:

- Answers calls to the existing business number using an approved clone of Jacob's voice, while clearly disclosing that it is an AI assistant.
- Answers business and rental questions accurately.
- Checks real availability and creates bookings through Jumping Jax's existing booking source of truth.
- Sends customers secure payment or deposit links without collecting card details inside the AI conversation.
- Transfers callers to a human whenever requested or when confidence is insufficient.
- Uses the native waiver data to identify upcoming child birthdays and sends the parent or guardian a consent-based 20%-off rental offer exactly six weeks beforehand.
- Supports SMS/email consent, opt-outs, annual deduplication, exclusions, expiration rules, delivery records, and redemption tracking.

Begin with discovery of the current repository, phone setup, booking workflow, waiver schema, and deployment environment. Consult only the Jumping Jax open-play/waiver Graphify memory and Open-Play-Waiver Obsidian vault for this project. Treat memory as a snapshot and verify important facts against current files.

Produce a simulated end-to-end prototype before enabling live actions. Add tests, audit logging, failure recovery, human escalation, security controls, documentation, and a production-readiness checklist.

Continue working through safe implementation steps until the system is verified and production-ready. Stop and request approval before purchasing services, porting or redirecting the phone number, creating paid accounts, deploying to production, sending real customer communications, processing real payments, or changing legal or marketing-consent language. Never store credentials in source control, Graphify, Obsidian notes, prompts, or documentation.
